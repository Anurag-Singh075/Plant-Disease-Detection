*# 🌿 Plant Disease Detection Using Deep Learning*



*A Deep Learning-based Plant Disease Detection application built using \*\*Python, TensorFlow, Keras, and Streamlit\*\*. The application helps identify plant diseases from leaf images using a trained CNN model.*



*## 🚀 Project Overview*



*Plant diseases can significantly affect agricultural productivity. This project uses Deep Learning and Image Classification to detect plant diseases from uploaded leaf images.*



*Users can upload a plant leaf image and get a predicted disease along with relevant disease information.*



*## ✨ Features*



*- 🌱 Image-based plant disease detection*

*- 🤖 Deep Learning using TensorFlow and Keras*

*- 📸 Upload leaf images for prediction*

*- 🔍 Automatic disease classification*

*- 📋 Disease information and details*

*- 🖥️ Interactive Streamlit web application*

*- ⚡ Real-time prediction interface*



*## 🛠️ Technologies Used*

*## ⚙️ Installation and Setup*



*### 1. Clone the Repository*



*```bash*

*git clone https://github.com/Anurag-Singh075/Plant-Disease-Detection.git*

*```*



*### 2. Navigate to Project Directory*



*```bash*

*cd Plant-Disease-Detection*

*```*



*### 3. Create Virtual Environment*



*```bash*

*python -m venv venv*

*```*



*### 4. Activate Virtual Environment*



*Windows:*



*```bash*

*venv\\Scripts\\activate*

*```*



*### 5. Install Dependencies*



*```bash*

*pip install -r requirements.txt*

*```*



*### 6. Add Trained Model*



*The trained model is not included in this GitHub repository because of its large file size.*



*Place the trained model at:*



*```text*

*model/plant\_disease\_model.keras*

*```*



*### 7. Run the Application*



*```bash*

*streamlit run app.py*

*```*



*The application will open in your browser.*



*## 🧠 Model Information*



*- Model Type: Convolutional Neural Network (CNN)*

*- Framework: TensorFlow / Keras*

*- Task: Image Classification*

*- Input: Plant Leaf Images*

*- Output: Predicted Plant Disease Class*
